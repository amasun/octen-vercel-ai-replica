### 1. Build agents on infrastructure that thinks like them

- Features
- Durable Orchestration
- Sandboxed Environments
- AI Model Gateway
- Fluid Compute

### 2. Ship apps that scale from zero to millions instantly
> **Zapier** serves over 100 million monthly website visits on Vercel.
- Features
- Global Delivery
- Deployment Environments
- Serverless Functions
- Web Application Firewall (WAF)

---

### 3. Host platforms that serve every customer
> **Mintlify** powers documentation for over 20,000 companies on Vercel.
- Features
- Tenant Isolation
- Domain Management

- Preview URLs
